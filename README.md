## 🚀 Featured Projects

### 🛡️ [DDoS-Detection](https://github.com/abdessamadhariri01-maker/DDoS-Detection)
`Python` `FastAPI` `Scikit-learn` `Streamlit` `CIC-DDoS2019`

ML-based DDoS attack detection system with a REST API backend serving pre-trained **Random Forest** and **SVM** classifiers, paired with a real-time Streamlit dashboard.

Trained on the **CIC-DDoS2019** dataset (77 network flow features), the system classifies incoming traffic as **BENIGN** or **DDoS** across three detection modes: manual single-input, CSV batch upload, and live traffic simulation.

**Highlights:**
- ⚡ FastAPI backend with 6 REST endpoints — model health checks, single & batch predictions, feature schema retrieval, detection statistics, and event history export
- 🧩 Pydantic-based request validation auto-aligning partial inputs to the full 77-feature schema
- 🎯 Confidence scoring layer — `predict_proba` for Random Forest, sigmoid-mapped `decision_function` for SVM
- 📊 Streamlit dashboard with Plotly real-time charts, DDoS alert banners, detection history table, and CSV export

### 📉 [Regularisation-ML](https://github.com/abdessamadhariri01-maker/Regularisation-ML)
`Python` `Scikit-learn` `Ridge` `Lasso` `ElasticNet`

Comparative analysis of L2 (Ridge), L1 (Lasso) and ElasticNet regularization on an energy-efficiency dataset (200 observations, 24 variables), evaluating how each technique handles overfitting when 10 of 23 features are pure noise.

**Key findings:**
- **Lasso (λ=1)**: strongest generalization — **−24.4% test MSE** vs. the unregularized baseline, automatically selecting only **4/23 features** and zeroing out all noise variables
- **ElasticNet (λ=0.1)**: balanced trade-off (−5.4% MSE, 21 features kept)
- **Ridge (λ=10)**: marginal improvement (−1.0%) by uniformly shrinking coefficients without feature elimination
